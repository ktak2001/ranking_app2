cloud run jobで実行できるような２つのスケジューラを用意したい。
１つ目は、set_youtubers.pyを毎日実行するようなものだ。
ただし、そこで呼び出す関数であるset_youtuber_superChatsにおけるget_videos_until_dateについて、現在はdefaultで2023,12,31になっているが、それをその日から5日前まで処理するように変更してほしい。

2つ目は、各vtuberの情報を週に一回updateするものだ。そのvtuberの画像や表示名は定期的に変更される可能性があるためである。

3つ目は、全supportersの情報を2週間に一回updateするものだ。同様に画像や表示名が変更されるためである。

gcloud scheduler jobs create http update_videos_everyday \
  --location asia-northeast1 \
  --schedule "0 3 * * *" \
  --uri "https://run.googleapis.com/v2/projects/$PROJECT_ID/locations/asia-northeast1/jobs/set-youtubers-job:run" \
  --http-method POST \
  --oidc-service-account-email scheduler-sa@$PROJECT_ID.iam.gserviceaccount.com
